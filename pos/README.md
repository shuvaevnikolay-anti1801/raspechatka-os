# Распечатка POS

Отдельное Windows-приложение рабочего места менеджера. Оно не является страницей Frappe: касса должна продолжать продажу даже при временном отсутствии интернета и напрямую работать с оборудованием Windows.

## Что уже есть в первом прототипе

- открытие смены;
- локальный каталог товаров и услуг;
- сбор чека и изменение количества;
- тестовая оплата наличными, картой, QR или несколькими способами;
- сохранение продаж во встроенную локальную SQLite;
- полные и частичные возвраты по исходному чеку;
- внесение и изъятие наличных, расчёт ожидаемого остатка кассы;
- очередь `outbox` с безопасной повторной отправкой событий в Frappe;
- синхронизация ассортимента и фактических остатков конкретной точки из Распечатка OS;
- поиск покупателя по телефону или имени, применение его скидки и запись состава покупки в историю клиента;
- свободная цена, если она разрешена настройками точки;
- повторная печать фискального чека через адаптер ККТ и печать товарного чека через системный диалог Windows;
- безопасные интерфейсы для кассы и эквайринга;
- тесты расчёта суммы в копейках.

Заказы, предоплаты и выдача заказов намеренно не входят в текущую кассу: сначала для них должна появиться единая модель заказов в Распечатка OS.

В обычном режиме касса поддерживает АТОЛ через локальный Web Server драйвера ККТ и эквайринг Точки/PAX
через официальный INPAS DualConnector (`DC Console.exe`). До включения оборудования операции безопасно
недоступны. `MockFiscalProvider` и `MockPaymentProvider` используются только при явном запуске с
`RASPECHATKA_TRAINING_MODE=1`. Товарный чек печатается через выбранный принтер Windows.

## Первый запуск на Windows

Запускайте POS из обычного Windows PowerShell, а не внутри WSL или Docker. Electron — это Windows-программа с окном и доступом к Windows-драйверам; WSL оставляем для Frappe.

```powershell
git clone https://github.com/shuvaevnikolay-anti1801/raspechatka-os.git
cd raspechatka-os
git switch codex/pos-foundation
cd pos
npm install
npm run dev
```

Потребуется Node.js 24 LTS. После установки Node.js закройте и снова откройте PowerShell.

## Сборка установщика

```powershell
npm run package:win
```

Установщик появится в `pos/release`. Подписание и автоматическое обновление добавим перед распространением на реальные точки.

Каждое изменение кассы в ветках `version-16` и `codex/pos-foundation` также запускает
GitHub Actions **POS Windows Installer**. Готовый файл
`Raspechatka-Kassa-Setup-<версия>.exe` можно скачать из артефакта
`Raspechatka-Kassa-Windows` соответствующего запуска.

После установки откройте раздел «Настройки», укажите адрес
`https://os.rpechatka.ru`, API key, API secret и код рабочего места. Ключи
хранятся зашифрованно средствами Windows и не встраиваются в установщик.
