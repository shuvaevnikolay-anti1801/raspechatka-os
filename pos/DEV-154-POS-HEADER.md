# DEV-154 — единая верхняя панель Windows POS

## Контекст

Актуальная stable: `version-16`.

В текущем `pos/src/renderer/src/AppV2.tsx` после авторизации выводятся две отдельные горизонтальные области:

1. `<header className="topbar pos-v2-topbar">`
   - `boot.pointName`;
   - отдельный статус `OS на связи / Локальный режим`;
   - `Заблокировать · {formatPersonShortName(boot.cashierName)}`;
   - условная кнопка `Выйти`.

2. `<nav className="main-nav">`
   - Продажа;
   - Чеки;
   - Заказы;
   - Смена;
   - Работа;
   - Настройки;
   - ещё один статус `OS на связи / Локальный режим`;
   - `К отправке: boot.pendingSync`;
   - `Обновить данные`.

`pos/src/renderer/src/styles.css` резервирует под них две строки:
`grid-template-rows:64px 52px minmax(0,1fr)`.

`formatPersonShortName()` уже существует в `renderer/src/person-name.ts` и должен продолжить использоваться.

## Цель

После входа кассира оставить сверху одну компактную панель в стиле текущей кассы.

Слева направо:

1. существующее меню: Продажа, Чеки, Заказы, Смена, Работа, Настройки;
2. свободное пространство;
3. один индикатор соединения:
   - зелёная точка + `OS на связи`;
   - либо offline-индикатор + `Локальный режим`;
4. кнопка блокировки кассы: `Заблокировать · Фамилия И.О.`;
5. кнопка `Обновить данные`.

## Поведение

- Удалить из рабочей панели отдельную кнопку `Выйти`.
- Не вызывать `logoutCashier()` из новой верхней панели.
- `lockCashier()` остаётся без изменения.
- `syncNow()`, `syncing` и `busy` остаются без изменения.
- Статус соединения показывается только один раз.
- Tooltip статуса:
  - при `boot.lastSyncAt`: `Последняя синхронизация: <локальная дата/время> · К отправке: N`;
  - иначе: `Успешной синхронизации ещё не было · К отправке: N`.
- `boot.pendingSync` не выводить отдельной постоянной надписью.
- `boot.pointName` убрать только из постоянного header. Данные точки и другие экраны не менять.
- Badge чеков/заказов и active-state навигации сохранить.

## Файлы

Менять только:

- `pos/src/renderer/src/AppV2.tsx`
- `pos/src/renderer/src/styles.css`
- `pos/src/renderer/src/pos-v2.css` — только удалить/адаптировать устаревшие `.pos-v2-topbar/.pos-v2-point`, если после новой разметки они больше не нужны.
- focused renderer test, только если в существующей тестовой инфраструктуре можно покрыть новый shell без создания новой test infra.

Не менять `main.tsx`, preload, IPC, shared contracts, backend, transaction/cart/payment/fiscal code.

## Разметка

В `AppV2.tsx` заменить соседние `topbar` + `main-nav` одним контейнером, например `header.pos-header`.

Внутри использовать две логические группы:
- `.pos-header-nav` — существующие компоненты `Nav`;
- `.pos-header-actions` — connection status, lock cashier, refresh.

Не создавать отдельный React-компонент только ради нескольких строк shell-разметки.

## CSS

В `styles.css`:

- `.app-shell` должен иметь одну строку header + рабочую область;
- высота единой панели ориентир 56–60 px;
- один фон, одна нижняя граница;
- navigation слева, actions справа;
- touch targets не меньше примерно 40 px по высоте;
- active underline/indicator текущего `Nav` сохранить;
- status visually secondary;
- lock button readable and clearly non-destructive;
- refresh secondary;
- при минимальной поддерживаемой ширине 1100 px не должно быть наложений; допускается умеренное уменьшение горизонтальных padding/gap.

Перенести toast вверх: он должен позиционироваться относительно новой одной панели, а не старых 64+52 px.

## Инварианты

Не менять:
- экран продажи;
- каталог;
- корзину;
- скидки;
- оплату;
- смены;
- `CashierAuthState`;
- `lockCashier/logoutCashier` API;
- синхронизацию данных;
- TransactionEngine;
- ATOL/INPAS.
