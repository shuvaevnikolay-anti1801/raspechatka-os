# Верхняя навигация и системные уведомления

## Главное меню

Верхняя панель реализована компонентом `frontend/src/components/TopNavigation.vue`.
Порядок разделов: Справочники, Главная, Продажи, Клиенты, Продукт, Склад, Финансы, Сотрудники.
Доступные пункты по-прежнему определяются матрицей доступа из boot payload.

Иконки выполнены встроенными SVG-контурами, поэтому не требуют внешней библиотеки или загрузки изображений.
На узких экранах основное меню переключается в компактную двухколоночную панель.

## Аккаунт

Меню аккаунта показывает текущего пользователя, открывает стандартные настройки профиля Frappe и выполняет выход через штатный endpoint `/api/method/logout`.

## Новости и уведомления

`System Announcement` хранит публикации администратора. Поддерживаются:

- черновик, публикация и архив;
- обычный и важный приоритет;
- период показа;
- аудитория: все, конкретная роль или конкретный пользователь.

`System Announcement Read` хранит отдельную отметку прочтения для каждой пары пользователь/уведомление.
Повторная отметка защищена проверкой уникальности в контроллере.

Frontend запрашивает публикации через `raspechatka.api.notifications.get_notifications`,
показывает счётчик непрочитанных и обновляет его раз в минуту.
Нажатие на публикацию вызывает `mark_notification_read`.

Административные методы:

- `save_announcement` — создание и изменение публикации, только для System Manager;
- `get_read_journal` — журнал пользователей и времени прочтения, только для System Manager.

Отдельный административный экран отправки новостей можно подключить к этим методам без изменения модели данных.
