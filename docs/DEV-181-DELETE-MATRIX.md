# DEV-181 — матрица зарегистрированных действий Admin Delete

| Тип | Стратегия | Зависимости / блокировка | Обратное действие |
|---|---|---|---|
| Sales Receipt | Черновик: hard delete; проведённый: cancel | Проведённые возвраты, производные записи черновика | Отмена восстанавливает остаток, прибыль, покупку клиента и итоги смены; внешнее событие подавляется |
| Sales Shift | Пустая: hard delete; иначе blocked | Чеки, движения наличных, нетехнические действия | Только собственные технические действия удаляются вместе со сменой; внешнее событие подавляется |
| Cash Movement | Черновик: hard delete; проведённое: cancel | Распределения оплат и производные записи черновика | Отмена финансовой транзакции и пересчёт смены |
| Stock Receipt | Черновик: hard delete; проведённая: cancel | Производные записи черновика | Обратная складская запись, пересчёт принятого по заказу |
| Stock Write Off | Черновик: hard delete; проведённое: cancel | Производные записи черновика | Обратная складская запись |
| Stock Inventory | Черновик: hard delete; проведённая: cancel | Производные записи черновика | Обратные записи разниц |
| Purchase Order | Черновик без связей: hard delete; проведённый без связей: cancel; иначе blocked | Приёмки и распределения оплат | Отмена документа без удаления истории |
| Employee | Без истории: hard delete; с историей: deactivate; с открытой сменой: blocked | Смены, чеки, касса, график, зарплата, документы, профиль и другие явные связи | Неиспользуемого можно создать снова; деактивированного можно активировать отдельно; профиль сохраняется |
| Business Point | Без истории: hard delete; с историей: deactivate | Все прямые ссылки на точку и ссылки на её склад, рабочее место, кассу и подключение | Пустая инфраструктура удаляется вместе с точкой; с историей точка и инфраструктура отключаются, данные сохраняются |
| Catalog Warehouse | Без ссылок: hard delete; со ссылками: deactivate | Обратные Link поля, включая отменённые документы | Можно активировать отдельно |
| Cash Register | Без ссылок: hard delete; со ссылками: deactivate | Обратные Link поля | Можно активировать отдельно |
| POS Workplace | Без ссылок: hard delete; со ссылками: deactivate | Обратные Link поля | Можно активировать отдельно |
| Catalog Item | Без ссылок: hard delete; со ссылками: deactivate | Обратные Link поля, включая строки документов | Можно активировать отдельно |
| Catalog Supplier | Без ссылок: hard delete; со ссылками: deactivate | Обратные Link поля, включая заказы и счета | Можно активировать отдельно |
| Client | Без ссылок: hard delete; со ссылками: deactivate | Обратные Link поля, включая историю клиента | Можно активировать отдельно |
| Business Entity | Без ссылок: hard delete; со ссылками: deactivate | Обратные Link поля, включая точки и документы | Можно активировать отдельно |
| Organization | Без ссылок: hard delete; со ссылками: deactivate | Обратные Link поля, включая юридические лица | Можно активировать отдельно |

Для любого незарегистрированного типа запрос блокируется. Проверки области доступа и права Admin выполняются на сервере до чтения документа. Исторические строки с `docstatus=2` также считаются ссылками. При появлении нестандартной ссылки без поля `Link` её требуется добавить в специальную проверку до разрешения физического удаления.
