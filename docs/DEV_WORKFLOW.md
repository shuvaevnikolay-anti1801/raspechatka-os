# DEV Workflow

1. Архитектор формирует DEV.
2. DEV разбивается на короткие Codex Task.
3. Codex получает только конкретную задачу.
4. После изменений выполняется проверка.
5. Создаётся PR.

## Формат Codex Task

Цель:
Что должно получиться.

Сделать:
Только необходимые изменения.

Не менять:
Что запрещено трогать.

Результат:
Критерии готовности.
