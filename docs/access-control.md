# Матрица прав доступа

## Источник страниц

Единый реестр разделов и страниц расположен в `frontend/src/access-pages.json`.
Из него одновременно строятся:

- верхнее меню;
- подменю;
- строки матрицы прав;
- список прав в boot payload;
- проверка прямого перехода по URL.

При добавлении страницы в меню её нужно добавить в этот реестр. При следующей миграции или
открытии страницы «Права доступа» соответствующая `Access Area` создаётся автоматически.

Каждая страница имеет собственный код `page.*`. Поле `legacy_area` сохраняет совместимость с
серверными проверками доступа. При первом переходе на новую модель существующие уровни
копируются из прежних укрупнённых областей, поэтому действующие пользователи не теряют доступ.

## Источник ролей

Столбцы матрицы формируются из всех активных рабочих записей стандартного DocType `Role`.
Служебные роли Frappe (`Guest`, `All`, `System Manager` и другие) скрыты. Новая рабочая роль
появляется в матрице автоматически и до явной настройки получает уровень «Не видно».

Уровни доступа:

- `None` — страница не видна и прямой переход заблокирован;
- `View` — чтение;
- `Edit` — чтение и изменение;
- `Admin` — административные действия.

Для роли `Raspechatka Network Admin` нельзя отключить административный доступ к самой матрице,
чтобы центральный администратор не заблокировал управление системой.

Область данных пользователя — сеть, партнёр, юридическое лицо или точки — применяется поверх
уровня страницы и не расширяется матрицей.
