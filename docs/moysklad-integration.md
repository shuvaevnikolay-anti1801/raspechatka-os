# Интеграция с МоимСкладом

## Назначение

МойСклад временно используется как внешний источник справочных данных для «Распечатка ОС». Первый этап интеграции только читает метаданные и примеры записей. Он не создаёт, не обновляет и не удаляет рабочие данные.

## Безопасность

- токен хранится в поле Frappe типа `Password`;
- API никогда не возвращает токен во frontend;
- адрес API зафиксирован на `https://api.moysklad.ru/api/remap/1.2` и не задаётся пользователем;
- экран и API доступны только пользователям с административным доступом `settings.access`;
- ошибки не содержат тело запроса, заголовок авторизации или токен.

## Первый этап: обзор

Экран `Справочники → МойСклад` позволяет сохранить токен, проверить соединение и прочитать количество записей с несколькими примерами по организациям, точкам продаж, складам, группам, единицам измерения, товарам, услугам, комплектам, модификациям, контрагентам и сотрудникам.

Фоновая задача запускается планировщиком каждые 15 минут и учитывает выбранный пользователем интервал. Она обновляет только сохранённый обзор. Значение `writes` в результате всегда равно нулю.

## Следующий этап: импорт

Перед включением записи необходимо согласовать правила:

1. соответствие организаций, точек и складов существующим записям;
2. создание внешних идентификаторов для групп, единиц, поставщиков и иных синхронизируемых сущностей;
3. разделение контрагентов на поставщиков и клиентов;
4. приоритет полей и поведение при архивировании в МоёмСкладе;
5. журнал запусков, идемпотентный upsert и режим пробного импорта.

До реализации этих правил импорт намеренно заблокирован.
