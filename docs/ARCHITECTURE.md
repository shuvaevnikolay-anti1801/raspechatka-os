# Распечатка OS Architecture

## Общая схема

Frontend
↓
IPC / API
↓
Services
↓
Providers
↓
Drivers / Integrations

## Правила

Новые интеграции должны использовать существующие слои.

Логика бизнес-процессов не должна находиться внутри драйверов.

Provider отвечает за связь бизнес-логики с внешними системами.
